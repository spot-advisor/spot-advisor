# Consultation rule experiment

## Frozen design

The development sample is the November 26 blind release check. Its 7/10 candidate score combines the initial decision, question formatting and subsequent attempts. Our hypothesis is that explicit instructions about how to submit a question and handle its reply will reduce repeated attempts while preserving correct first decisions. The treatment is a single replacement for the first numbered paragraph of the current 2.3 skill. Both arms receive the entire skill. This estimates the effect of the combined wording.

**Primary outcome.** Measure the difference in exact correct next actions across 16 previously unused, author-written decision scenarios. Each scenario has a legitimate alternative. Run the same scenario once per arm in fresh Luna Max sessions. Lock the scenario, permitted actions and grading key before the first response. Score the first response only. For consultation, require a single tool call with a question of at least 16 characters ending in a question mark and nonempty evidence. Report raw paired wins, losses and ties, percentage-point change and exact two-sided McNemar p from discordant pairs. This is a diagnostic convenience sample. The test assumes exchangeable paired outcomes and generalization to other workloads requires independent cases.

**End-to-end check.** Run two fresh attempts per arm on each of the five existing release fixtures with the real consultation transports. These fixtures have been used for development. Record original strict timing, fixture acceptance, terminal verification, local rejections, all attempted consultations and receipt-confirmed dispatches. The common harness permits one corrected submission after an identified local format rejection and withholds the text of invalid advice. Count every attempted call in the historical strict grade. An interrupted or unavailable assignment stays in the denominator with zero credit. Record uncertainty for missing usage. Do not pool the two experiments.

**Assignment and decision.** Randomize pair order and arm order within each pair, with seed 971. Use the same route, reasoning effort, prompt wrapper and tool set within each comparison. Hide keys and arm labels from Luna. Run no more than four sessions at once. Each diagnostic session permits one executor response within 60 seconds. Each live session has a 150-second budget and at most one frontier dispatch. Use existing subscription routes. Run one unscored local-repair smoke first. Freeze both instruction texts, the protocol, harness, grading key, media identities and assignments in a new run directory. Compare after every scheduled assignment finishes. No resampling, optional stopping for favorable outcomes, or tuning on this batch.

Keep the current rule as default unless the primary gain is positive with a two-sided paired p below .05, the candidate clears all ten end-to-end timing, delivery and terminal verification checks, and candidate lookup attempts do not increase. This pilot may motivate another test even when that adoption criterion is unmet. An external confirmation needs unseen task authors, a fresh environment and sample size chosen from a minimum useful effect and expected paired discordance.
