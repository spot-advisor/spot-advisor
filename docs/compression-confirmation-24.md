# Spot Advisor 2.4 matched compression study

Freeze the following rules before the first pilot outcome. The study estimates effects on an equal mixture of published programming, chart-reading and short English transcription tasks. Hosts and first-use testing are separate product acceptance cohorts. The recordings, charts and programming prompts are public and may have been seen during model training.

## Inputs and assignments

Use sanitized MBPP test, ChartQA test and FLEURS en_us test at the three pinned Parquet revisions in [the sampler](../eval/compression_inputs24.py). Keep one MBPP prompt, one question per unique chart digest and one recording per FLEURS sentence ID and transcript. The seeded shuffle is separate per modality. Allocate the first six per modality to pilot and reserve the next sixty. Each independent source item supplies one checkpoint with actual byte identity, brief, observable file metadata, local inspection and decision question. Keep gold keys and private assertions outside model messages.

Within each task, give every arm the same Luna executor, question, original media, advisor route, one advice opportunity and 180-second deadline including preparation and grading. Text and image use Astra medium on Codex. Audio uses the tested Gemini subscription audio model via the local gateway. The same host records an A full checkpoint, a B free summary produced by Luna, and a C production scoped packet. B and C each have a 4,000-character text ceiling including the question. Include actual costs for B's summary, all response attempts and final submission. Use the same four-line advice instruction and decoder for A, B and C within each modality. The executor gets the same local checkpoint and its arm's usable advice; it submits a Python module or an answer file. Save the submitted bytes even if verification fails. A missing answer or deadline miss counts as a failure on the assigned row.

Assign all three arms before dispatch and balance order with the six permutations within modality. The first 18 tasks are for calibration. At equal true quality, use the upper one-sided 80% Clopper–Pearson bound on observed A/C pilot discordance as the design variance. Use the standard normal paired approximation with one-sided alpha .05, power .80 and a 5-point noninferiority margin. Round up to equal blocks of six tasks per modality, cap at 180 formal tasks and disclose when the uncapped target exceeds the cap. With no evaluable pilot pairs, retain the cap and mark the design variance unknown. Never use a formal outcome to change sample size, prompts, grading or the product.

## Grading and claims

Dispatch in the registered balanced order; concurrent calls can overlap in wall time. The full-checkpoint reference contains actual local observations, including the complete structured probe output. The media bytes themselves are identical across arms. On short tasks the scoped packet can be longer than the full reference. Preserve that comparison.

MBPP uses the original public and held-out assertions in a fresh pinned, network-isolated Python container. A chart answer accepts a case-insensitive string match or a numeric value within 5% relative error of a nonzero reference. A numerical zero requires exact zero. For FLEURS compute word error rate after Unicode case-folding, punctuation-to-spaces and whitespace normalization on the submission and reference. Pass at WER no higher than 15%. The grader reads the task and file bytes without arm information. These perception tasks have reference answers; subjective preferences are outside the study.

Primary quality contrast is the paired C minus A verified-by-deadline rate, equally weighted across modalities. Use a one-sided 95% lower confidence bound via a paired score interval (Tango's score inversion for paired proportions). To claim noninferiority it must exceed −0.05. Report B, C–B and modality-specific results descriptively. Bootstrap 10,000 times stratified by modality, keeping task triples intact, for estimated cost-per-verified-delivery ratios. An upper one-sided 95% bound of 0.90 or lower supports the cost claim only with identified usage and prices for all required components. Missing billing data stays unknown, including unpriced media models. Report measured executor/advisor inputs, outputs, cache, timeouts, failures and elapsed time independently.

The freeze includes the sampler, study runner, pricing inputs, selection and grader hashes. Retain the first outcome for every assignment. If a dispatched call lacks a terminal receipt, record an interrupted assignment and continue with independent jobs. Revisions to the freeze after outcomes are known require a separate cohort. Regenerate tables from published rows, with a separate label for pilot, product acceptance and confirmation. Positive results are optional for publication.
